usage: indra-ocr-viewer [-h] [--model-dir MODEL_DIR] [--mode {auto,ocr,text}]
                        [--model-order] [--no-image-ocr] [--version]
                        [--port PORT] [--threads THREADS] [--dpi DPI]
                        [--max-pages MAX_PAGES] [--keep-furniture]
                        [--tesseract] [--tesseract-lang TESSERACT_LANG]
                        [--math]

Local viewer: drop in a PDF or an image, see what Indra OCR reads.

    indra-ocr-viewer                      # models from the Hugging Face repo
    open http://localhost:8765

Each page shows its lines, layout blocks and reading order over the page (each
can be shown or hidden), the rendered markdown, the markdown source, the lines
with their confidences, the JSON the CLI writes, where the text came from (the
PDF text layer, OCR, or both) and the time of each stage.  The pipeline options
(text layer or OCR, math, page headers and footers, reading order, OCR of text
inside images, dpi) are set in the page and apply when the document is read
again.  Pages are read one at a time and appear as they finish.  With
--tesseract (needs the tesseract binary and pytesseract) the page can also run
Tesseract on each page.

options:
  -h, --help            show this help message and exit
  --model-dir MODEL_DIR
                        folder with the models (default: download from Hugging
                        Face)
  --version             show program's version number and exit
  --port PORT
  --threads THREADS
  --dpi DPI             initial PDF render resolution
  --max-pages MAX_PAGES
                        initial page limit per document
  --keep-furniture      initially keep page headers and footers
  --tesseract           allow comparing with Tesseract
  --tesseract-lang TESSERACT_LANG
  --math                initially write math as LaTeX

text layer or OCR (PDFs):
  --mode {auto,ocr,text}
                        auto: text layer where it passes the checks, OCR
                        elsewhere (default); ocr: never read the text layer;
                        text: use the text layer even when the checks fail
  --model-order         order text-layer lines with the order model, not the
                        PDF content order
  --no-image-ocr        on text-layer pages, do not OCR text inside images
